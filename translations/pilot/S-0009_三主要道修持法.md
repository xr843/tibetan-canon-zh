# 依《三主要道》根本颂调正正行之修持法

## 解题

本篇是一部观修仪轨：行者先观想以文殊上师为主的资粮田，作皈依、发心、七支供；然后设想自己逐一向上师请问，上师以宗喀巴大师《三主要道》（出离心、菩提心、空性正见）的十四偈作答，行者随声诵出，并依贡塘的提示作意观修；最后收摄资粮田、回向。书后附贡塘另一篇愿文。

## 译例

- 引自《三主要道》根本颂的偈句，标为【根本颂 n】；其余偈颂为贡塘所作或仪轨通用偈。
- 圆括号里是译者为通顺而补的字；方括号里是解说。
- 底本疑有讹误之处，出“校注”。

## 正文

**〔礼赞〕**
赤黄自身光明，赭色法衣严饰，
如谷响般，以自声自作教诫，
以无边幻化，作众生之怙主——
愿彼文殊上师恒常摄护！

**〔一、明观皈依境〕**
复次，凡欲依《三主要道》根本颂调正正行、以之为修持心要者，当先明观以至尊上师为主之皈依境，令皈依与发心和合于自相续而得决定，然后将皈依境融入自身。复观想：

　具三恩之文殊上师，周围有加持近传诸上师，
　及诸上师、本尊、诸佛与佛子所围绕，
　无量皈依境（于前）安住。

[即：自根本上师乃至文殊本尊之间，加持近传诸上师层叠而住，皆现赤黄文殊之相；其上为金刚持；左右为广大行传承与甚深见传承等诸上师；此外，四部续之本尊、诸佛、菩萨、声闻、缘觉及护法，一切皈依境无一不具，明观为资粮田。]

广修则诵“如母有情遍虚空”与“尽其所有”（《普贤行愿》）等；略修则诵：

　超过无边刹土微尘数，无数诸佛之智慧身，
　无边总集文殊怙主之体性——顶礼诸至尊上师！

如是礼敬；但诵末句亦可。次（诵七支）：

　实设意化诸供悉奉献，无始所积罪堕尽忏悔，
　随喜诸善、劝请并祈祷，以此为表诸善回向大菩提。

（次供曼扎，诵）“地基涂香……愿享清净刹”。（次祈请：）

　为令我等脱离三有之牢狱，安乐趣行真实妙道故，
　一切颠倒分别之系缚，祈以深广教授之利剑斩断！

**〔二、上师许说〕**
如是祈请时，观想资粮田一切圣众及主尊根本上师文殊，面含微笑，以梵音宣说：

【根本颂 1】诸佛一切圣言之心要义，诸胜佛子所共称赞之道，
　　　　　具缘求解脱者趣入之津梁——我当随力而宣说。

【根本颂 2】凡于三有安乐不贪著，为令暇满有义而精勤，
　　　　　信依令佛欢喜之道者——诸具缘者，当以净心谛听！

作是想：上师许为宣说，并劝令谛听。（行者）以随声复诵之方式，自己诵出。以下各处皆同。

**〔三、出离心〕**
次，（行者）请问：“最初当如何斩断三有之系缚？”（上师答：）“于此三有之中，并非他人令汝不由自主而受系缚，乃是自己贪著三有圆满所欺诳。譬如飞蛾以为灯焰中有乐，他人遮止亦不能止，扑入其中而受苦。是故须生出离心。”于此教诫生起信解，（诵：）

【根本颂 3】若无清净出离心，则于三有海希求安乐果，无由止息；
　　　　　且由贪著三有，有身之众遍受系缚——是故最初当求出离。

如是诵。复请问：“然则出离心如何生起？”（上师答：）“当以暇满与无常相结合，遮止对今生之贪恋；以业果不虚与轮回过患相结合，遮止对来世之贪恋；（由此）生起于轮回之圆满盛事亦不贪著之出离心。又，此心非如偶尔生起一次即足，须于所缘令心串习，乃至梦中亦能忆念。”于此教诫生起信解，（诵：）

【根本颂 4】暇满难得，寿命无暇，数数串习，遮止今生之贪恋；
　　　　　业果不虚，轮回诸苦，数数串习，遮止来世之贪恋。

【根本颂 5】如是串习，于轮回圆满盛事，刹那希慕亦不生起，
　　　　　日夜恒常希求解脱之心若生，尔时即是生起出离心。

**〔四、菩提心〕**
如是诵。复请问：“唯以出离心为主而修，是否已足？”（上师答：）

【根本颂 6】此出离心若不为清净发心所摄持，
　　　　　则不成无上菩提圆满安乐之因——是故诸具慧者，当发最胜菩提心。

作是想：上师教诫须发菩提心。复请问：“若须发起能得无上菩提之心，当如何发起？”（上师答：）“唯欲得佛果，尚为不足。当以修习悲悯有情为主；由悲心之自力，引生欲得佛果以为其支分——彼时即是生起发心。”作是想：上师如是开示，并诵：

【根本颂 7】为猛烈四大瀑流之相续所漂，为难遮之业索紧紧束缚，
　　　　　陷入我执铁网之中，为无明黑暗之大昏雾所遍覆，

【根本颂 8】于无边三有中生而复生，为三苦无间相续所逼恼——
　　　　　思惟如是处境之诸母之情状，当发最胜心！

**〔五、空性正见〕**
如是诵。复请问：“于此二者之上，道之增补尚须何者？”（上师答：）

【根本颂 9】若不具足通达实相之慧，虽串习出离心与菩提心，
　　　　　亦不能断三有之根——是故当勤通达缘起之方便。

（此谓）须有真实正见。复请问：“此正见当如何修持？”（上师答：）“于现与空二者，不可有亲有疏；须于二者无违、双运之理，获得深固之定解。若得此解，即是得令诸佛欢喜之妙道。”作是想：上师如是慰勉，（诵：）

【根本颂 10】凡于轮回、涅槃一切法，见其因果永无欺诳，
　　　　　且一切所缘执之着落悉皆坏灭——彼即趣入令佛欢喜之道。

【根本颂 11】显现为缘起无欺诳，与空性离一切承许——此二种理解，
　　　　　乃至各别显现之时，犹未通达能仁之密意。

【根本颂 12】何时不更迭而同时，但见缘起无欺诳，
　　　　　即坏定解所执境之一切执持方式——尔时正见之观察方为圆满。

【根本颂 13】又以现相除有边，以空性除无边，
　　　　　若知空性现为因果之理，则不为执边之见所夺。

如是缓缓诵出。

**〔六、上师劝修〕**
次作是想：于真实道获得殊胜定解之欢喜，了知此乃至尊上师恩德之信心，以及“自今以后，亦当以此道为修持心要”之勇悦，三者互相竞赛般增长。尔时至尊上师亦（说）：

【根本颂 14】如是三主要道之扼要，汝自如实通达之时，
　　　　　当依寂静处，发起精进之力，速疾成办究竟之所求——吾子！

作是想：上师以极欢喜之态劝勉修持。复执至尊上师之足，（白言）：“悲悯上师，我当依您之教言修持。愿我三时一切善聚，皆成如您所教而成办之因！祈请永不分离而摄受，加持修持究竟！”如是猛利祈请时，资粮田诸尊从边际收摄，融入根本上师；根本上师融入自身，作是想：已得加持。

**〔七、回向〕**

　以此善根，愿我生生世世，与胜导师——上师您不相分离，
　以怙主您心中所出精华、善说甘露之味而活命！

　复次，我所已作及当作之一切善妙行，
　愿成您欢喜摄受、唯依教奉行之因！

以如是等回向作结。

**〔跋〕**
此乃应乌珠穆沁旗具慧然绛巴贡却格丹（dkon mchog skal ldan）之请，比丘贡却丹贝仲美所撰；书写者为咒然巴贡却衮噶（dkon mchog kun dga'）。

　离障善逝心意之明镜面上，दྷཱིཿ（底）、ཧཱུཾ（吽）字所游戏之智慧尊，
　虽为一切佛之祖，而现童子之相——愿怙主智慧之藏，长久摄护！

　愿后世一切生生不堕之鬘，与文殊甘露之光相伴，
　以加持显现之吉祥功德护持，行于真实道之虚空界！

　愿以如虚空界之慧，遍满杂染、清净、取舍之无边大地，
　得抉择甚深法真实性之无碍智慧！

　愿以斩断一切未解、邪解之网的智慧利剑之锋，
　拔除实执系缚之根，趣入解脱之洲！

　愿善达一切圣言之真实性，以无畏讲、辩、著之智慧，
　善竖不衰之教幢，为众生开饶益安乐之喜宴！

　愿于无谬善慧（洛桑）胜者之教，闻至究竟无厌足，
　以真实修持为心要，闻、思、修三慧增长！

　总之，愿得辨别取舍、唯一正见之眼的殊胜智慧，
　依次行于显密胜乘之妙道，趣入一切种智之洲！〔校注 2〕

## 校注

1. 根本颂 1 第三句底本作 འཇུག་དགོགས，通行本作 འཇུག་ངོགས（津梁、渡口），底本为形近之讹。
2. 愿文末颂底本作 མནོར་ཐེག་མཆོག་ལམ་བཟང，“མནོར”不成词，疑为 མདོ་སྔགས（显密）之讹，今依此译。
3. 第一则愿文的“底、吽”二字，是文殊心咒的种子字，按惯例保留藏文。

## 质量检验：十四偈与参照译本对比

参照译本：果硕仁波切网站《圣道三要》十四偈汉译（2021，未署译者）。（参照译文受他人著作权保护，公开版不收录，仅保留比对结论。）

| 偈 | 本译要点 | 判断 |
|---|---|---|
| 1 | 圣言心要义、佛子称赞道、求解脱者津梁、随力宣说 | 一致 |
| 2 | 不贪三有乐、令暇满有义、信依佛喜道、净心谛听 | 一致 |
| 3 | 无清净出离则希求有海乐果无由止息；贪著三有令有身者受缚；故先求出离 | 一致 |
| 4 | 暇满难得、寿无暇，遮今生贪；业果不虚、轮回苦，遮来世贪 | 一致 |
| 5 | 于轮回圆满刹那不慕、日夜求解脱，即生出离 | 一致 |
| 6 | 出离若无发心摄持，不成无上菩提因；当发菩提心 | 一致 |
| 7–8 | 四瀑流、业索、我执铁网、无明昏雾；生生三苦；思诸母发胜心 | 一致 |
| 9 | 不具实相慧，虽修出离、发心，不能断有根；当勤通达缘起 | 一致 |
| 10 | 见一切法因果无欺；所缘执着落坏灭；即入佛喜道 | 一致 |
| 11 | 现分缘起无欺、空分离承许，二者各别现时，未达佛意 | 一致（“离承许”与“离实执意”措辞不同，见下） |
| 12 | 不更迭同时见缘起无欺即坏执取方式，正见观察圆满 | 一致 |
| 13 | 现除有边、空除无边；知空现为因果，不为边见所夺 | 一致 |
| 14 | 通达三要扼要时，依静处精进，速成究竟所求 | 一致 |

**结论**：14 偈在义理层面与参照译本全部一致，没有发现漏译或义理相反的地方。差异只在措辞，最明显的是第 11 偈“空分离一切承许”（ཁས་ལེན་བྲལ་བ），参照译作“远离实执意”：本译按字面，参照取意译。两种理解在格鲁派讲解中都常见，需要人工判断取哪种。

**这次检验看不到的**：参照译本只覆盖十四偈根本颂（约占全篇三分之一）；贡塘自己的观修指导、仪轨偈和愿文没有参照，准确性只能由懂藏文的人审定。
