## 一、归敬与立宗

> ན་མོ་གུ་རུ་མཉྫུ་གྷོ་ཥཱ་ཡ།

南无古如曼殊廓喀耶（敬礼上师妙音）！

> ལྷག་པའི་ལྷ་དང་དབྱེར་མེད་བླ་མ་ལ། །གུས་པས་བཏུད་ནས་སེམས་དང་སེམས་བྱུང་གི་ངོས་འཛིན་མདོར་བསྡུས་ཚིག་གིས་རབ་བརྗོད་དེ། །ཆོས་མངོན་རྒྱ་མཚོའི་ཡང་སྙིང་བཤད་པར་བྱ། །

恭敬顶礼与本尊无别之上师；以简略之辞，宣说心与心所之辨识，讲述对法大海之精髓。

## 二、心与心所之总相

> ཡུལ་གྱི་ངོ་བོ་ཙམ་ཞིག་རིག་པ་སེམས། །

唯了知境之体性者，是**心**。

> ཡུལ་དེ་ཉིད་ལ་དམིགས་པ་གཞིར་བྱས་ནས། །བྱེད་ལས་ལ་སོགས་ཁྱད་ཆོས་གཞན་གྱི་ནི། །ལྡོག་པས་ཡུལ་ལ་འཇུག་པ་སེམས་བྱུང་ཡིན། །

以缘彼境为所依，而由作用等其余差别法之分位趣入于境者，是**心所**。

> སེམས་ལ་མིག་དང་རྣ་བ་སྣ་དང་ལྕེ། །ལུས་དང་ཡིད་ཀྱི་འཇུག་ཤེས་རྣམ་དྲུག་དང། །སེམས་བྱུང་ཀུན་འགྲོ་ཡུལ་དེས་དགེ་བ་དང། །རྩ་ཉོན་ཉེ་ཉོན་གཞན་འགྱུར་དྲུག་ཏུ་ཡོང། །

心有眼、耳、鼻、舌、身、意六种转识；心所则分为遍行、别境、善、根本烦恼、随烦恼、不定六类。

## 三、遍行五

> ཀུན་འགྲོར་ཚོར་བ་འདུ་ཤེས་སེམས་པ་དང། །རེག་པ་ཡིད་ལ་བྱེད་དང་རྣམ་ལྔ་སྟེ། །

遍行有五：受、想、思、触、作意。

| 心所 | 本论（译文） | 〔五蕴论〕 |
|---|---|---|
| **受**（ཚོར་བ） | 各别领受业之异熟——乐、苦与舍。 | 谓三领纳：一、苦，二、乐，三、不苦不乐。 |
| **想**（འདུ་ཤེས） | 境、根、识三者和合，而各别分辨境之相状。 | 谓于境界，取种种相。 |
| **思**（སེམས་པ） | 令与自相应之心，不由自主趣入于境。 | 谓于功德过失及俱相违，令心造作，意业为性。 |
| **触**（རེག་པ） | 境、根、识三者和合，了别境之（可意、不可意、中庸）三种，为受之所依。 | 谓三和合分别为性。 |
| **作意**（ཡིད་ལ་བྱེད） | 令与自相应之心，执持别别所缘。 | 谓能令心发悟为性。 |

> སེམས་རྣམས་ཀུན་ལ་རྗེས་སུ་འགྲོ་བས་ན། །དེ་དག་རྣམས་ལ་ཀུན་འགྲོར་བརྗོད་པ་ཡིན། །

由随行于一切心故，此五名为遍行。

## 四、别境五

> ཡུལ་དེས་ལ་ཡང་འདུན་པ་མོས་པ་དང། །དྲན་པ་ཏིང་འཛིན་ཤེས་རབ་རྣམ་ལྔ་སྟེ། །

别境亦有五：欲、胜解、念、三摩地、慧。

| 心所 | 本论（译文） | 〔五蕴论〕 |
|---|---|---|
| **欲**（འདུན་པ） | 缘所思之事而希求，为精进之所依。 | 谓于可爱事，希望为性。 |
| **胜解**（མོས་པ） | 于量所决定之境，如是执持，不为他所引转。 | 谓于决定事，即如所了印可为性。 |
| **念**（དྲན་པ） | 于串习之所缘不忘失，以令心不散乱为业。 | 谓于串习事，令心不忘明记为性。 |
| **三摩地**（ཏིང་འཛིན） | 于所观之事相续安住之心一境性，为智之所依。 | 谓于所观事，令心一境不散为性。 |
| **慧**（ཤེས་རབ） | 各别抉择所观察事之过失与功德，以断除疑惑为业。 | 谓即于彼择法为性。 |

> དེ་དག་རྣམས་ཀྱིས་ཡུལ་གྱི་ཁྱད་པར་དེ། །བཟུང་ནས་འཛིན་པར་བྱེད་པས་ཡུལ་ངེས་སོ། །

此五各取境之差别而执持之，故名别境。

## 五、善十一

> དགེ་བར་དད་དང་ངོ་ཚ་ཤེས་པ་དང། །ཁྲེལ་ཡོད་མ་ཆགས་མི་སྡང་གཏི་མུག་མེད། །བརྩོན་འགྲུས་ཤིན་སྦྱངས་བག་ཡོད་བཏང་སྙོམས་དང། རྣམ་པར་མི་འཚེབ་དང་བཅུ་གཅིག་སྟེ། །

善有十一：信、惭、愧、无贪、无瞋、无痴、精进、轻安、不放逸、舍、不害。

| 心所 | 本论（译文） | 〔五蕴论〕 |
|---|---|---|
| **信**（དད་པ） | 信解、澄净、欲求三者随一，为不信之对治，为欲之所依。〔校注 1〕 | 谓于业果诸谛宝中，极正符顺，心净为性。 |
| **惭**（ངོ་ཚ་ཤེས་པ） | 以自身为因由，而避讳罪过。 | 谓自增上，及法增上，于所作罪羞耻为性。 |
| **愧**（ཁྲེལ་ཡོད） | 以他人为因由，而避讳过失。惭、愧二者，皆为防护恶行之所依。 | 谓世增上，于所作罪羞耻为性。 |
| **无贪**（མ་ཆགས） | 于三有及三有资具，心生厌离而无贪著。 | 谓贪对治，令深厌患无著为性。 |
| **无瞋**（མི་སྡང） | 于能生瞋之三种境，无欲作损害之恚恼心。 | 谓瞋对治，以慈为性。 |
| **无痴**（གཏི་མུག་མེད་པ） | 由生得及修习所生、为愚痴对治之妙观察慧。 | 谓痴对治，以其如实正行为性。 |
| **精进**（བརྩོན་འགྲུས） | 于善勇悍欣乐，以圆满善品为业。 | 谓懈怠对治，心于善品勇悍为性。 |
| **轻安**（ཤིན་སྦྱངས） | 身心堪能，以除遣一切障为业。 | 谓麁重对治，身心调畅堪能为性。 |
| **不放逸**（བག་ཡོད） | 依无三毒与精进，修习善法，防护有漏。 | 谓放逸对治，即是无贪乃至精进；依止此故，舍不善法及即修彼对治善法。 |
| **舍**（བཏང་སྙོམས） | 得第九住心时，（于对治昏沉、掉举之功用）……〔校注 2〕 | 谓即无贪乃至精进；依止此故，获得所有心平等性、心正直性、心无发悟性。 |
| **不害**（རྣམ་པར་མི་འཚེ་བ） | 属无瞋之分，以悲心而不讥毁（他人）为业。 | 谓害对治，以悲为性。 |

> དེ་རྣམས་ཀུན་སློང་སོགས་ལ་མི་ལྟོས་པར། །གྲུབ་ཙམ་ཉིད་ནས་དགེ་བས་དགེ་བར་བརྗོད། །

此十一不待等起等，但由自体成就即是善故，说名为善。

## 六、根本烦恼（六，开为十）

> རྩ་ཉོན་འདོད་ཆགས་ཁོང་ཁྲོ་ང་རྒྱལ་དང། །མ་རིག་ཐེ་ཚོམ་འཇིག་ལྟ་མཐར་ལྟ་དང། །ལྟ་བ་མཆོག་འཛིན་ཚུལ་ཁྲིམས་བརྟུལ་ཞུགས་ནི། །མཆོག་འཛིན་ལོག་ལྟ་དང་བཅས་རྣམ་བཅུ་སྟེ། །

根本烦恼有十：贪、瞋、慢、无明、疑，以及萨迦耶见、边执见、见取、戒禁取、邪见。

| 心所 | 本论（译文） | 〔五蕴论〕 |
|---|---|---|
| **贪**（འདོད་ཆགས） | 于有漏事见为可意，而希求之。 | 谓于五取蕴染爱耽著为性。 |
| **瞋**（ཁོང་ཁྲོ） | 缘三种境而不能忍，欲作损害之恚恼心。 | 谓于有情乐作损害为性。 |
| **慢**（ང་རྒྱལ） | 缘内外高下，具傲慢、高举行相之心。 | 谓……心高举为性（分七慢）。 |
| **无明**（མ་རིག་པ） | 于一切法实相愚昧之无知心，为百过所生之依。 | 谓于业果及谛宝中无智为性。 |
| **疑**（ཐེ་ཚོམ） | 于谛犹豫两端，以障碍善为业。 | 谓于谛等犹豫为性。 |
| **萨迦耶见**（འཇིག་ལྟ，坏聚见） | 缘近取蕴，执为我、我所之染污心。 | 谓于五取蕴随观为我或为我所，染污慧为性。 |
| **边执见**（མཐར་ལྟ） | 缘我而见为常或断之染污慧。 | 谓即由彼增上力故，随观为常或复为断，染污慧为性。 |
| **见取**（ལྟ་བ་མཆོག་འཛིན） | 缘见及蕴，执为最胜之染污慧。 | 谓即于三见及彼所依诸蕴，随观为最为上为胜为极，染污慧为性。 |
| **戒禁取**（ཚུལ་བརྟུལ་མཆོག་འཛིན） | 见以恶劣之戒禁等能得解脱之染污心。 | 谓于戒禁及彼所依诸蕴，随观为清净为解脱为出离，染污慧为性。 |
| **邪见**（ལོག་ལྟ） | 见因果、前后世等为无之染污慧。 | 谓或谤因或复谤果、或谤作用或坏善事，染污慧为性。 |

> དེ་རྣམས་སྐྱེས་ཙམ་ཉིད་ནས་སེམས་ཀྱི་རྒྱུད། །རབ་ཏུ་མ་ཞིར་བྱེད་པས་ཉོན་མོངས་ཡིན། །

此等才一生起，即令心相续极不寂静，故名烦恼。

## 七、随烦恼二十

> ཉེ་ཉོན་ཁྲོ་བ་ཁོ་ན་འཛིན་འཆབ་པ་དང། །འཚིག་དང་ཕྲག་དོག་སེར་སྣ་སྒྱུ་དང་གཡོ། །རྒྱགས་དང་རྣམ་འཚེ་ངོ་ཚ་ཁྲེལ་མེད་དང། །རྨུགས་དང་རྒོད་པ་མ་རང་ལེ་ལོ་དང། །བག་མེད་བརྗེད་ངས་ཤེས་བཞིན་མ་ཡིན་དང། །རྣམ་གཡེང་དང་བཅས་ཉི་ཤུ་ཐམ་པ་སྟེ། །

随烦恼共二十：忿、恨、覆、恼、嫉、悭、诳、谄、憍、害、无惭、无愧、惛沉、掉举、不信、懈怠、放逸、失念、不正知、散乱。

| 心所 | 本论（译文） | 〔五蕴论〕 |
|---|---|---|
| **忿**（ཁྲོ་བ） | 损害之缘现前时，欲作捶打等损害之恚恼心。 | 谓遇现前不饶益事心损恼为性。 |
| **恨**（ཁོ་ན་འཛིན） | 不舍瞋之相续，欲以损害报复损害。 | 谓结怨不舍为性。 |
| **覆**（འཆབ་པ） | 他人举（己）过时，由愚痴欲隐藏其过。 | 谓于自罪覆藏为性。 |
| **恼**（འཚིག་པ） | 他人举过时，以怨恨心欲出粗恶语。 | 谓发暴恶言尤蛆为性。 |
| **嫉**（ཕྲག་དོག） | 贪著利养恭敬，不忍他人圆满，心相续扰乱。 | 谓于他盛事心妒为性。 |
| **悭**（སེར་སྣ） | 贪著利养恭敬，紧执资具而不能施舍。 | 谓施相违心吝为性。 |
| **诳**（སྒྱུ） | 贪著利养恭敬，自无功德而显似有。 | 谓为诳他诈现不实事为性。 |
| **谄**（གཡོ） | 贪著利养恭敬，欲于他人隐瞒自过。〔校注 3〕 | 谓覆藏自过方便所摄心曲为性。 |
| **憍**（རྒྱགས་པ） | 于所得有漏圆满，欢喜安乐，心相续充满（自负）。 | 谓于自盛事染著倨傲心恃为性。 |
| **害**（རྣམ་འཚེ） | 于众生无悲悯心，欲加讥毁，属瞋之分。 | 谓于诸有情损恼为性。 |
