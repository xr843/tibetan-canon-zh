# 松绷目录 藏→汉译名规范

## 总原则

1. **简体中文**。不加书名号。
2. **有通行汉译的，用通行汉译书名**（见末尾“已有汉译书名”），译名类型标“已有汉译”。只有确信是同一部书时才这样标。
3. 没有通行汉译的，**按藏文书名意译**，保留藏文书名的结构：「主题 + 体裁 + 美称」。例如 `…rnam bshad … rgya mtsho` → 「……广释·……海」。美称（比喻性的尾名，如“白莲鬘”“如意宝”）要保留，和主题部分用间隔号「·」隔开。
4. 书名太长时（超过约 40 个汉字）可以适当压缩，但主题、体裁、美称三部分都要留下。
5. 人名用通行汉译（宗喀巴、贾曹杰、克主杰、帕绷喀、章嘉、嘉木样协巴、贡塘……）；没有通行译名的，按拉萨音用常见汉字音译，同一个人全书保持一致。
6. 不要编造：拿不准的词照字面译，并在“说明”栏写明拿不准的地方。不要为了通顺而增加藏文书名里没有的内容。
7. 中性对待各派别和有争议的题目（如 rdo rje shugs ldan 只音译为“多杰雄登”，不加评价）。

## 输出格式

每行一条，用制表符分隔：

```
编号	汉文书名	译名类型	说明
```

- 译名类型只能是以下四种之一：`已有汉译` / `沿用dhammareader` / `校订dhammareader` / `新拟`。
  - `沿用dhammareader`：原译名正确、符合本规范，只做繁转简。
  - `校订dhammareader`：原译名有错误、不通顺，或用词与本规范不一致，你作了修改。在“说明”栏用一句话写明改了什么。
  - `新拟`：原来没有汉文译名。
- 说明：没有可写的就留空。拿不准的地方必须写。
