# 翻译路线图

2026-11-21 制定。每月回顾一次：只排后面约 3 个月的具体书目，更远的只定阶段和顺序。

## 一、为什么要分阶段、按单元推进

藏文大藏经里没有汉译的显教典籍篇幅极大。按总目录统计（不含密续，也不含有版权问题的），标“未见汉译”的：

| 部 | 篇幅 | 其中较大的部类 |
|---|---|---|
| 丹珠尔 | 约 2,700 万音节 | 量论 527 万、律 416 万、般若 377 万、中观 353 万、对法 216 万、唯识 189 万 |
| 松绷 | 约 2,500 万音节（不含传记） | 般若 428 万、戒律 314 万、量论 289 万、中观 252 万、道次第 189 万 |
| 甘珠尔 | 约 190 万音节（经部、宝积部） | 经部 90 部，145 万音节 |

目录的“未见汉译”漏得很多：唯识部核查后，约一半其实已有现代汉译。即使打对折，单是丹珠尔中观部，按目前的速度（推算每周 5–10 万音节）也要好几年。所以不可能“一类全部译完再做下一类”，改为：

- **按单元推进**：一个单元是一部本论，加上它的印度注疏（丹珠尔）和藏地注疏（松绷）。三部藏经按同一个主题串起来，不各走各的。
- **按阶段推进**：每个阶段写明“做到哪里算完”。完成本阶段的核心单元，就进入下一阶段；没做的转入长期队列。
- **核查总表先行**：每进入一个新部类，先做这一类的汉译核查总表（格式同 [唯识部](汉译核查总表_唯识部.md)），再从中选单元。

## 二、三层结构

1. **路线图**（本文件）：定阶段、顺序和每阶段的完成条件。
2. **单元**：开工前先完成三件事：
   - 单元内各书的核查结论；
   - 单元术语表，沿用已发布译稿的译名；
   - 单元的完成条件。
3. **单部书**：照 [翻译规范](翻译规范.md) 和 [实施流程](实施流程.md) 执行：三道核查 → 翻译 → 审核 → 发布。

**阶段 A 的结束方式**：海云戒品释已过三道核查，但比对发现它约六成文字与已发布的胜子《菩萨戒品广释》（T-2955）相同，而且分布在全篇（详见 T-2955 解题）。菩萨戒注释单元在内容上已经齐全，所以不再单独翻译，转入长期队列，以后做成与 T-2955 逐段对读的版本。维护工作（术语统一、松绷补审）照常在后续阶段穿插进行。

**单元候选会因核查而变**：核查查到已有汉译的书，即移出单元；整个单元都已有汉译的，就换下一个候选单元。

## 四、长期队列

篇幅大或需要先查清前译范围的书，不设终点，在各阶段之间穿插：

- 海云《菩萨地广释》：戒品释做成与 T-2955 的对读版；其余各品（真实义品已有韩镜清译本）逐品翻译；
- 安慧《大乘庄严经论疏》：须先查清韩镜清译到哪里；
- 《秘密义分别略说》（T-2961）：须先查清它本身注释的范围；
- 佛护《中论释》（T-2749）、莲花戒《中观光明论》（T-2795）、宝生寂《集经论释宝光庄严》（T-2843）；

宗喀巴《末那与阿赖耶难处广释·善说海》（S-0414）原在本队列，2026-11-22 查到北塔网站已公开土登达瓦的现代汉译（连同根本颂），移出队列。

## 五、甘珠尔

甘珠尔里没有汉译的经，与大慈恩译经基金会“月光藏”的翻译范围重合度很高。暂不作为主线：

- 先做一次覆盖调查：把月光藏已译、在译的清单与本项目目录对照；
- 只在两种情况下翻译甘珠尔的经：某个单元的本经确实没人译过；或明确不在其他团队计划内。

## 六、节奏

- 每周：主线翻译一部，同时做一项维护，维护约占两成（推算）。
- 每月：回顾本路线图，更新阶段状态和后面 3 个月的书目。
- 维护包括：术语统一、补做审核、核查结论复查（超过 3 个月的要重查）。
