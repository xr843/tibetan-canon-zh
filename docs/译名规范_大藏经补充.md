# 甘珠尔、丹珠尔书名译名规范（补充）

本规范是对 `docs/译名规范.md` 的补充。体裁词、本尊名、“简体、不加书名号、不编造、拿不准写说明”等原则沿用原规范；原规范中“人名与称号”一节针对藏地祖师，这里基本用不上。

## 一、总原则

1. 甘珠尔是佛语，丹珠尔多是印度论师的论著，原书名大多是**梵文**，藏文是意译。所以要同时看藏文书名、梵文书名和 84000 英文书名：
   - 汉传有通行译名的，**一律用通行译名**（见第三节），类型填“已有汉译”，在说明里写出所据的汉译（如“玄奘译 T1585”或“通行译名”）。
   - 没有通行译名的，按汉译佛典的书名习惯意译。
2. 书名要像汉译佛典，简洁，不要逐字硬译、也不要过度压缩：
   - 'phags pa → 圣；dpal → 吉祥（续部、本尊名前）；zhes bya ba → 名为（通常省略）。
   - theg pa chen po'i mdo → 大乘经；mdo → 经；gzungs → 陀罗尼；snying po → 心要 / 心咒（视语境）。
   - rgyud → 续；rgyud kyi rgyal po → 续王；rtog pa → 仪轨（续部）。
   - bstan bcos → 论；rab tu byed pa → 论（prakaraṇa）；tshig le'ur byas pa → 颂。
   - 'grel pa → 释；rnam par bshad pa / rnam bshad → 广释；dka' 'grel → 难语释；ṭīkā / 'grel bshad → 疏；bsdus pa'i don → 摄义。
   - sgrub thabs → 成就法；dkyil 'khor gyi cho ga → 坛城仪轨；dbang bskur ba'i cho ga → 灌顶仪轨；sbyin sreg → 火供；gtor ma → 朵玛。
   - bstod pa → 赞；spring yig → 书 / 书翰（如《亲友书》）；man ngag → 教授；sgron ma → 灯；'phreng ba → 鬘；snang ba → 光明。
3. 本尊名按原规范统一：'jigs byed 大威德金刚；bde mchog / 'khor lo sdom pa 胜乐金刚；gsang 'dus 密集金刚；dus 'khor 时轮金刚；kye rdo rje 喜金刚；rdo rje rnal 'byor ma 金刚瑜伽母；gshin rje gshed 阎魔敌（红阎魔敌 / 黑阎魔敌）。
4. 品名、卷次：原书名里有“第几品”“上卷/下卷”的照译，保留。
5. 同一部书在不同编号出现（如异译、重出），书名可以相同，在说明里注明“与 Dxxxx 同名”。

## 二、处理 dhammareader 原译名

- 每条给出 dhammareader 的原译名（已转简体）。忠实于藏文/梵文、符合本规范的，类型填 **沿用dhammareader**。
- 有错译、漏译（例如漏了“难语释”“广释”等体裁词）、术语不合本规范、或不像汉译佛典书名的，修改后类型填 **校订dhammareader**，说明栏用一句话写改了什么。
- 确认是汉传通行书名的，类型填 **已有汉译**。

```
编号	汉文书名	译名类型	说明
```
