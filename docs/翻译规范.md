# 翻译规范

本项目所有汉译稿都按这份规范制作。AI 译者开工前必须先读完它。规范来自试点和第二批的实际经验，每条后面注明了出处。

## 一、选书条件

按 [翻译路线图](翻译路线图.md) 分阶段推进：唯识 → 中观义理 → 修习与道次第 → 五部大论其余。每个阶段完成本类的核心单元就进入下一阶段，其余的书转入长期队列。每译完一部，本地保存，同时发布到 GitHub。


一部作品要同时满足以下三条，才进入翻译：

1. 没有现成汉译，包括古代汉译和近现代汉译。总目录的“汉译情况”一列漏得很多，**不能只看它**：唯识部目录标“未见汉译”的 36 部中，核查后有 18 部已有现代汉译。具体做法见下面第 1 节。
2. 没有著作权问题：作者在 1955 年以前去世，并且不在 dhammareader 的版权剔除名单里。作者生卒年不详的，见第 3 节。
3. 有校正版底本：优先用 dhammareader 校正版，其次用 Esukhia 德格版。底本缺叶的，见第 3 节。

### 1. 汉译核查：先核查，后开工

**核查前置**：三道核查（见 [实施流程](实施流程.md) 第五节）全部完成、结论写进核查总表之后，才能切分底本、建工作目录、开译。

**已知译者目录**：先对照已知的现代译者目录。
- 尤其是韩镜清（1912–2003）：他几乎译遍了丹珠尔唯识部的核心注疏，还译了法称因明论典、《现观庄严论》的大批注释，约 70 种，以《韩镜清翻译手稿》出版，所用书名常与通行书名不同。
- 再联网检索法尊、吕澂、任杰、大慈恩译经基金会等人的译本，以及各地的学位论文和期刊。

**核查结论有有效期**：别的译者还在不断出新译，例如大慈恩译经基金会 2025–2026 年仍在陆续发布。
- 开译前，核查日期距今超过 3 个月的，必须重查一次。
- 核查总表的结论栏要写明核查日期，以及做了哪几道核查。

**已有汉译的分级处理**：

| 级 | 已有汉译的情况 | 处理 |
|---|---|---|
| 甲 | 完整的古译或现代汉译，已出版或已公开发布，质量可靠 | 不译 |
| 乙 | 有完整汉译，但质量明显有问题（如古译晦涩、错漏多），或者只有未公开的稿本 | 可以重译。解题中说明理由，注明已有译本的出处 |
| 丙 | 只译了一部分（如只译了某几品、译到一半） | 只补译缺的部分。先查清前译的起止位置（写到叶码），再定补译范围 |
| 丁 | 只译了本颂，释文未译；或只有释文，本颂未译 | 只译未译的那一部分。颂与释在目录里分为两条的，各按各的情况定级 |
| 戊 | 别人正在翻译（如圆满法藏目录标“翻译中”“进行中”） | 暂不开译，状态记为“观望”。半年后复查：对方发布了，按甲至丁处理；仍没有发布，可以联系对方或改为开译 |

- **讲记、白话讲解、沿用古译的对照本**都不算译本。
- 现代译者在其他书中转引的片段，也不算译本。
- 定级拿不准时，按较严的一级处理。比如分不清是甲还是乙，就按甲处理。

**开译以后才查到前译**：
- 已经译完的：照常发布，解题中列出前译。前译属于甲级的，发布前先请项目负责人决定（先例：T-2988《般若波罗蜜多教授》，决定照常发布）。
- 还没译完的：停在当前段，按上表重新定级。是丙级或丁级的，只继续译前译没有覆盖的部分。

### 2. 排序：同等条件下先译哪部

符合上面三条的候选，按以下顺序考虑：

1. **有可以核对的依据**：本论有古译、有平行文本，或者同一作者有已译的著作。
2. **能和已发布的译稿连起来**：补齐一个注释系列，或者接上已译的本论、根本颂。
3. **价值**：用总目录的“注疏数”一列，以及注释关系表中“这部书被多少部著作注释”来衡量，两者都多的优先。这一项只在前两项差不多时用来决定先后，不推翻前两项。
4. **篇幅先小后大**：进入一个新大类时，先译 1–2 万音节的论典，把术语定下来，再译大部头。

### 3. 底本与作者的条件

| 情况 | 规则 |
|---|---|
| 底本缺叶 | 缺失部分估计在全书 10% 以内，可以译，但解题和正文中都要标出缺在哪里（先例：《俱舍论摄义》缺约 7%）。超过 10% 的，先去找完整的版本 |
| 估算缺失比例 | 缺叶数乘以本书每叶平均音节数，再除以全书估计音节数 |
| 作者归属有争议 | 可以译。解题中列出各种说法和出处，不作断定 |
| 作者生卒年不详 | 先查清。能确定作者在 1955 年以前去世的才译；查不清的不译 |
| 只译全书的一部分 | 选的必须是原书的自然单元（品、卷、章）。解题中交代全书的结构，以及本稿在全书中的位置 |
| 书中有密法内容 | 书名属于显教、但内容有灌顶、生起次第、圆满次第、本尊修法的，整部不译。道次第类的书只在末尾简略提到密乘的，可以译，解题中说明 |

## 二、文件格式

- 文件名：`<总编号>_<简短书名>.md`。
- 文件头写明：总编号、ACIP 编号、藏文书名、作者及生卒年、底本路径与音节数、译者，并加一行“AI 翻译，未经人工审定”。
- 正文前依次是“解题”和“译例”。
- 正文按意义分段，段落编号为〔n〕。每段先列藏文（放在 `>` 引用块里，保留原书叶码），再列汉译。
- 书末依次是：校注、异文表（有对校本时才有）、引文核对表、自查。
- 科判用小标题层级呈现。论辩部分用【他宗】【自宗】【问】【答】标明谁在说话。

## 三、藏文必须完整

全文都要翻译，不得删节。完成后用脚本核对：把各段藏文拼起来，必须与底本逐字一致（空白除外）。

## 四、引文

- 每条引文都要到本机 CBETA 检索核对。
- **古代译本可以采用**（玄奘、鸠摩罗什、真谛、施护等，CBETA T 编），转成简体，标注格式：〔引文：出处，CBETA 编号，页栏行〕。
- **现代译者的译文不得采用**（法尊等 1955 年以后去世的译者，CBETA B 编、G 编），也不得在标注、校注里抄录原句。这类引文一律依藏文自译，标注格式：〔引文：出处，自译；参 CBETA 编号 页栏行〕。（第二批《四谛建立》因此返工了 26 条）
- 查不到的引文，标“自译”；连出处都拿不准的，写“出处待考”。**不得凭记忆编造出处、卷数、页码。**
- **校注里写“某疏说”“某书云”的，必须是那部书确有的内容**，并注明叶码；译者自己的推断、串讲一律写成“译者按”，不得记在别人名下。（2026-11-21《二谛分别论释》校注 93 把疏中没有的话记作“难语释说”，由 Claude 审核查出）

## 五、专有名词（最高风险）

- 人名、地名、寺名、书名拿不准时，**正文照字面翻译，比定只写在校注里**，并列出依据。
- **绝不补出原文没有的专有名词。**试点中曾把“大士所作之释”编成人名“色唐巴”；第二批中曾把“真实谛”直接写成“真谛”，后来都改回了字面译法。
- 术语依照 `译名规范.md`。俱舍术语用玄奘译名，中观术语用通行译名。

## 六、底本讹误

- 疑有讹、脱、衍时，出校注说明，不得悄悄改正；按改读翻译的地方，要在校注里写明。
- 有对校本时（同一部书的另一个传本），要逐音节比对，列出异文表。

## 七、自查

书末“自查”一节必须包括：

- 引文核对统计：采用几条、自译几条、出处待考几条；
- 最没把握的 10 处，写明段号和原因；
- 这次检查看不见什么，例如没有汉文参照的部分。

## 八、交稿前的机器检查

运行 `precheck_public.py`，检查以下几项：

- 是否含本机路径或个人信息；
- 是否含参照译文原句；
- 是否采用了 B 编、G 编的现代译文；
- 是否混入藏文全文。

不通过就不能交稿。

## 九、丹珠尔（印度论典）的补充规定

1. **两本对校**：底本用 dhammareader 校正的 ACIP 本，并逐音节对校 Esukhia 德格版。两者都出自德格版，所以异文多为录入差异。有实义差别的出校注，并列出异文表。
2. **古译对勘**：CBETA 中已有的古译（多为宋代据梵本译出）可以作参照，但**必须从藏文翻译**，不得照抄古译。
   - 古译与藏文有实义差异的地方（增、删、次第不同、解读不同），出“对勘注”，并标明古译的 CBETA 页栏行。
   - 古译的书名与术语，可以在解题中说明对应关系。
3. **审核（2026-11-19 起）**：
   - **Claude 整部审核**：由没有参与翻译的全新 Claude 子代理审核整部译稿。凡能用依据（藏译本论、疏、古译、对校本）核实的都要核实，并列出“需要第二意见的地方”。
   - **Codex 重点复核**：Codex（另一家的模型）只复核三类位置：译者自查里最没把握的 10 处、Claude 审核员列出的“需要第二意见”的地方、没有汉文参照的论证段落。
   - **Codex 抽样整部审核**：每 3–5 部抽 1 部，交 Codex 整部审核，用来检验 Claude 审核是否有系统性的漏洞。
   - 审核意见由原译者逐条处理：采纳的改正；不采纳的写明理由。审核记录附在译稿末尾，并如实写明每部由谁审核、审了哪些部分。
4. **密续不译**：密续及密续释部的作品不列入翻译，理由是宗派传承与灌顶要求。
